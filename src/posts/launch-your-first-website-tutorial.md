If your new year's resolutions include AI coding / vibe coding or finally building your idea into a website, try finding 15 minutes to give it a shot by following this tutorial I built: [launchyourfirstwebsite.com](https://launchyourfirstwebsite.com)

The tutorial is a step by step guide based on what I've learned in the last two months playing around with Claude Code to build out my [first website](/posts/hello-world-post-pt2), and then many more side project ideas since then. I even built the site for this tutorial by following the same steps.

There are lots of services nowadays that help you do the same thing (Replit, Lovable, etc). Personally, having so many options to choose from often gets me stuck on researching the best ways to get started instead of actually getting started, and easier to put it off altogether.

So I've put this tutorial together in a way that I hope is super straightforward and sufficient to get you through a proven path that worked for me, going end to end all the way from idea in your head to live website that anyone can visit.

If you do try this out and run into any blockers, leave a comment or reach out.
